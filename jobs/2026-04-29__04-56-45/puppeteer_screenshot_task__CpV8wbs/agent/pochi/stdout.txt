- Navigate to `https://example.com`
- Take a full-page screenshot
- Save it as `example_com.png` in the screenshots directory
- Print the run ID to the console

- `executablePath`: `/usr/bin/google-chrome-stable` (or `PUPPETEER_EXECUTABLE_PATH` env var)
- `args`: `["--no-sandbox", "--disable-setuid-sandbox"]`
